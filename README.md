# D4v1iS Portfolio

Static multi-page neon-purple portfolio for **D4v1iS**.

## Pages
- `index.html` — Home
- `about.html` — About, skills, and journey
- `projects.html` — Featured projects
- `contact.html` — Contact channels

## Music integration
The site embeds the requested Spotify track using the official Spotify player (`open.spotify.com/embed`).
Autoplay is intentionally not forced because browsers and Spotify restrict unsolicited playback.
Use the floating **Music player** button, then press play in the embed.
